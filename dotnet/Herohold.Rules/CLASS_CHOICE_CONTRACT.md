# Native class-choice contract

`ClassChoiceRules(ClassProgressionCatalog, RulesCatalogSnapshot, BeastChoiceCatalog, SpellCapabilityCatalog)` provides `OwnedKeys(className)`, `Describe(ClassChoiceContext,targetLevel)` and `ForLevelUp(context,currentLevel,targetLevel)`. It interprets only known schema fields and reviewed named feature rules. It never executes source descriptions, mutates canonical choices, saves characters or launches Python.

Ownership covers every feature-specific `class_options` path: styles/orders/extra cantrips, class and subclass Expertise, languages, metamagic, invocations/arcanum, Wild Shape, Scholar/Savant/Spell Mastery/Signature Spells, Battle Master/Student of War, Lore, Hunter, Beast Master and Land choices. Root creation owns identity, base/background/species choices, class_skills, equipment, ordinary spell quotas, ASI/general feats and UI translation. Compose by canonical path and reject duplicate owners. OwnedKeys includes future inactive paths so generic descriptors cannot expose them prematurely.

Context includes canonical class/subclass identities, level, raw class-option selections, current feature configurations, typed per-source proficiency records, source-owned cantrips, spellbook/Savant ownership and the legacy Rogue starting-Expertise fallback. `ClassChoiceContextFactory.FromCanonical(canonical,NativeBuildSummary)` creates a detached context. NativeBuildSummary.ProficiencySources records each independent owner; source IDs for class options are exactly `class_options:<key>`. Overlapping owners remain separate. Known inactive warrior/order parents do not authorize cantrip grants; Pact of the Tome requires active invocation selection and an invocation-owned grant source, not a label from another source kind.

Each ClassChoiceDefinition separates NewOptions, ValidExistingOptions, unchanged PreservedSelection and configuration-aware EffectiveSelection. ValidSelected is a distinct eligible subset for preview only. Selection shape, duplicates, excess values and ineligible values make Status Unresolved. Stable error codes are selection_shape, duplicate_selection, too_many_selections, ineligible_selection and missing_selection; issue path is `[class_options,key]`. Neither raw selections nor their order are repaired silently. Adoption must reject unresolved reports.

All 2024 subclass effects begin at the class selection threshold 3. Blessed/Druidic Warrior dependencies begin at 2. An inactive definition produces no active grant. Per-definition source exclusion validates existing Expertise/languages separately from new choices, preventing an option from authorizing itself while preserving independent proficiency sources. Ranger Expertise cannot choose a skill with Expertise from another source. Wizard Scholar requires a supported proficient skill. Wizard 18 mastery requires a level 1/2 Wizard spell in the actual spellbook with exact structured casting_time `1 action`; Wizard 20 signatures choose two level 3 Wizard book spells. Savant selections preserve per-threshold ownership and exclude other owned/book spells.

Fighting Style permission is the complete ten-feat universe for Fighter/Paladin/Ranger, plus Blessed Warrior for Paladin or Druidic Warrior for Ranger. This is an approved correction to legacy restricted fallback lists, verified against the 2024 Free Rules class features: https://www.dndbeyond.com/sources/dnd/br-2024/character-classes . Existing trusted option order is retained, then missing styles append in fixed Fighter-style order.

SpellChoiceRules uses only explicit class membership, level, school code, casting time and exclusion sets. Cross-list/cantrip/arcanum results sort by ordinal name; source-filtered/Savant/mastery queries preserve catalog order. SpellCapabilityCatalog reads structured raw damageInflict fields. Damaging invocation cantrips must be level 0 and actually count as Warlock spells, including verified Pact of the Tome sources; off-class origin/species grants do not qualify. Reviewed invocation prerequisites are retained for normalized object records and name-only fallback records. Repeatable invocation instance bindings and active effects remain explicitly unmodeled where existing source support is partial.

BeastChoiceCatalog reads the separate trusted 35-record beasts JSON. Wild Shape filters creature type/CR/flying fields and orders by CR then ordinal name. WeaponCapabilityCatalog joins normalized weapon mastery records to raw XPHB category/Finesse/Light properties; typed proficiency selectors distinguish Monk MartialLight from Rogue MartialFinesseOrLight without reading captions. Missing property metadata never grants Light/Finesse permission.

Context bounds include level 1–20, 100 class-option/configuration entries, 1000 proficiency sources, 500 cantrip sources, 5000 spellbook entries and 1000 Savant records. Source parsers bound bytes/depth/records. Invalid current choices remain repairable; oversized or malformed structural contexts fail visibly. No next-stage workflow writes occur in this module.
