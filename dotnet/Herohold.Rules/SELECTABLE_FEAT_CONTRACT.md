# Additional selectable feats

`NativeSelectableFeatCatalog.Parse(rawFeatsJson).AdditionalDefinitions` returns detached normalized definitions for 2024 XPHB Origin and ordinary Fighting Style feats. The public seven-key catalog retains its 55-feat contract. The current trusted source produces 22 additional definitions: twelve Origin variants (Magic Initiate has separate Cleric, Druid, and Wizard entries) and ten Fighting Styles. Blessed Warrior and Druidic Warrior remain class-level alternatives, not generally selectable Fighting Style feats.

`FeatSelectionRules(snapshot, extraDefinitions = null, tools = null)` accepts these additional trusted definitions and an optional `ToolCatalog`. Existing callers retain the original universe. `AvailableDefinitions` returns detached complete definitions; native level-up uses that universe. Fighting Styles require the Fighting Style feature and are not repeatable. Skilled is repeatable. Each Magic Initiate list is independently nonrepeatable; different lists are permitted. The caller includes background, species, class style, and general-feat owners in `FeatRuleContext.OwnedFeats`.

IDs are lower-case underscore names plus `_xphb`: `magic_initiate_wizard_xphb`, `skilled_xphb`, `defense_xphb`, and `two_weapon_fighting_xphb`. Spell grant and numeric rule names remain canonical, such as `Magic Initiate (Wizard)` and `Defense`.

Magic Initiate fields are `spellcasting_ability`, `cantrips` (two distinct same-list level-zero spells), and `spell` (one same-list level-one spell). Skilled uses `proficiencies` (three distinct `Skill: Insight` or `Tool: Lute` values); existing `skills`/`tools` arrays remain accepted and normalized. Crafter and Musician use three concrete `tools`; injected tool metadata controls eligibility. No ability-score adjustment is created for feats that grant no score increase.

The raw parser is bounded and rejects unsupported prerequisites rather than silently granting permission. Definition reads and spell/choice selections are detached. Tests cover actual 22-definition membership, source isolation, missing feature prerequisites, owner-aware duplication, fixed spell lists, concrete tools, and malformed input. Primary category/repeatability and Magic Initiate evidence: https://www.dndbeyond.com/sources/dnd/br-2024/feats (2024 Free Rules, retrieved 2026-10-26). The fixed XPHB source supplies the additional catalog records and tool choices.
